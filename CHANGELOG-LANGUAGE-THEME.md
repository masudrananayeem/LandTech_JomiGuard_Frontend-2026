# Language and Theme Update

## Added
- English/Bangla language toggle in both Client and Admin top bars.
- Light/Dark theme toggle in both apps.
- Language and theme preferences persist in browser localStorage.
- Shared visual treatment for preference controls and light-mode overrides.
- A starter English-to-Bangla UI dictionary that translates common navigation, actions, headings, and system messages.

## Notes
- This is a lightweight UI translation layer for the hackathon prototype. Some long technical explanations, data-derived strings, and OCR outputs may remain in English until each screen is moved to explicit translation keys.
- Light mode has broad overrides; inspect all pages and contrast before public deployment.
- Preferences are stored locally in the browser, not on the server.
